# Time Digital website (Next.js)
1. `npm install`  2. `npm run dev` (http://localhost:3000)  3. `npm run build && npm start`
Edit phone, email, WhatsApp number, prices, services and project images in `lib/data.js`.
Put images in `public/images/` and set e.g. `image:'/images/project1.jpg'` in the `work` list.
